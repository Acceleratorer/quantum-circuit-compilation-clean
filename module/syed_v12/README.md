# Syed v12 source pointer

The binaries are deliberately excluded from Git. Download the Apache-2.0 source dataset with:

```powershell
kaggle datasets download syed3000/vqcc-own-circuit-portfolio -p new_download/datasets_recent/syed_own/files --unzip
```

The exact member hashes and archive hash are in `manifest.json`. The source dataset includes deterministic `build.sh` files for all three tasks, plus `LICENSE`, `NOTICE`, and `SHA256SUMS`.
