# Winner source-delivery requirements

The host states that prize eligibility requires a circuit generator that produces the exact submitted circuits for all benchmarks. Public compiled inputs can be used for a leaderboard probe, but the source lineage must be pinned before treating the archive as prize-ready.

Source: [Kaggle discussion 752010](https://www.kaggle.com/competitions/google-verifiable-quantum-circuit-compilation/discussion/752010).
