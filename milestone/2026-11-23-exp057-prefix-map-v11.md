# exp-057 branchless prefix inverse gate

**Status:** Component gate passed; integrated schedule pending.

Private Kaggle kernel v11 verified the branchless prefix-to-coefficient map at
`Q=888`, `T=9,262` on 32 cases covering both pivot branches. It preserved the
rank/pivot and 66 spectator words, left 39 scratch qubits clean, and produced
no phase flips. The prior v10 map cost `T=22,954` at `Q=889`.

The inverse 2x2 matrix uses
`N00=6*a0^2+12*a0`, `N01=a0*(6*a1+10)`, and
`N11=6*a0+6*a1^2+10*a1+12`, with determinant
`20*W0*W1*W2`. A fixed pivot
`u=6*a0*(a0+a1+1)/20` is nonzero on the supported domain. The algebraic
factorization passed 256 seeded local GF(2^12) cases.

The gate is still a separate four-word cell. The integrated 4+66 schedule and
official DQI verifier remain the next required milestone. No competition
submission was made.
