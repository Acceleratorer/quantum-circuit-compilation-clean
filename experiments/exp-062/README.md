- Dataset: [`syed3000/vqcc-own-circuit-portfolio`, version 17](https://www.kaggle.com/datasets/syed3000/vqcc-own-circuit-portfolio/versions/17)
- License: Apache-2.0; original `LICENSE` and `NOTICE` are in [`upstream/`](upstream/).
- Source tree: 1,019 files, 31,891,406 bytes; tree SHA-256 is in the [source provenance receipt](receipts/source_provenance.json).
- The advertised outer source archive was unavailable. The kernel copied the published extracted `syed_source/` tree and deterministically regenerated missing `.json.gz` inputs from their matching JSON source files.
- No public `.kmb` or `.kmx` circuit was copied or read. The build hash-gated the generated bytes before calling the official verifier.

The kernel source is [`kernel/rebuild_verify.py`](kernel/rebuild_verify.py).
The stage hashes, lineage, and cut hashes are in the [build receipt](receipts/build_receipt.json); the exact verifier output is in [verify_full.json](receipts/verify_full.json). Raw run logs are under [`kaggle_output/`](kaggle_output/).
