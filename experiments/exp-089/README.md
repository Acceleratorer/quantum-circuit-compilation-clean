# exp-089 — QV2 DQI source rebuild

This experiment ports the DQI source from the Apache-2.0 QV2 kit at
[`src/dqi/qv2_m4`](../../src/dqi/qv2_m4/README.md), builds it in a **private,
offline Kaggle kernel**, and checks the exact output with the competition's
official verifier. It rebuilds a ported upstream design; the known table
lineage is disclosed in [`UPSTREAM.md`](../../src/dqi/qv2_m4/UPSTREAM.md). It
does not make a competition submission.

## Measured result

Kernel version 2 rebuilt the exact upstream circuit hash
`3c03fa53dd86be8e2ea3caa5d37597d371bc49426605a57a6ae8d31adc3c2ef3` and passed
the official verifier on 102,400 shots. It measured Q=889, mean T=333,238.013,
repetition factor 1.205584, three value errors, and zero phase errors. The
verifier score is `317,508,715,032.39`.

Substituting this measured DQI into S-001 projects to `32.42186`; that is not a
Kaggle score. The refreshed leaderboard puts rank 1 at `34.66186`, a gap of
`2.24000`. The derived DQI tie gate is `259,844,583,724.07`, so this result is
22.19% above it. At Q=889 and the measured repetition factor, the tie gate
corresponds to about 272,717 mean T; the current build is about 60,521 T above
that estimate. See the [live gate receipt](../../evals/2026-11-27-live-gate-153613Z.json)
and the [verifier receipt](../../evals/2026-11-27-exp089-qv2-dqi-source.json).

The kernel package is generated by `package_kernel.py` into an empty directory
outside the Git checkout. It contains the small runner and pinned source hashes;
the public Kaggle dataset supplies the source files at runtime. The runner checks
each hash and copies only the pinned DQI source and attribution files. Kaggle
internet access is disabled. The generated `.kmb` stays in the private kernel
output and is not committed here.

## Reproduce

```powershell
py -3.14 experiments/exp-089/package_kernel.py ..\exp089-kernel
uvx --with six --from kaggle kaggle kernels push -p ..\exp089-kernel
```

The destination must be empty. The private kernel is
[`accelra/exp-089-qv2-dqi-source-verification`](https://www.kaggle.com/code/accelra/exp-089-qv2-dqi-source-verification),
version 2 for the recorded result.
